Tuchka

A small cloud that keeps your passwords and types them into the browser in one click.

Download for Windows

Tuchka.exe · Windows 10 and 11 · nothing to install

Free for private persons. Organisations need a license.

Tuchka runs on a Windows computer. Open this page there, or send the link to yourself.

How to start

  1. Download Tuchka.exe and run it.
  2. Create a master password. It opens the vault and cannot be recovered, so remember it.
  3. Import the passwords from the CSV file of your browser, or add them by hand.
  4. On a login page click the floating cloud or press Ctrl+Alt+P: the login and the password are typed in.

Good to know

  • Works with Chrome, Edge and Firefox.
  • The passwords stay on your computer, in one encrypted file. Nothing is sent anywhere.
  • The first time, Windows may say it does not know the program: choose More info, then Run anyway.
