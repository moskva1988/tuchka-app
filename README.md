# Tuchka

A small cloud that keeps your passwords and types them into the browser in one click. For Windows 10 and 11.

**[Download Tuchka.exe](https://github.com/moskva1988/tuchka-app/releases/latest/download/Tuchka.exe)** · [the page of the program](https://moskva1988.github.io/tuchka-app/)

1. Download `Tuchka.exe` and run it — there is nothing to install.
2. Create a master password. It cannot be recovered, so remember it.
3. Import the passwords from the CSV file of your browser, or add them by hand.
4. On a login page click the floating cloud or press Ctrl+Alt+P.

The passwords stay on your computer, in one encrypted file. Nothing is sent anywhere.

The first time, Windows may say it does not know the program: choose **More info**, then **Run anyway**.
